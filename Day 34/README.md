# Day 34 - Intermediate+ API Practice - Creating a GUI Quiz App
It’s a revisit of my [Day 17](</Day 17/quiz-game-start-zip>) from the 100 Days of Code challenge, where I first built a console-based quiz game. This time, I upgraded it with a graphical interface and interactive buttons.

## Features
- GUI powered by Tkinter
- True/False questions with instant feedback
- Score and question tracking
- Instant color feedback (green/red)
- End screen once quiz is finished
