# Day 36 - Intermediate+ Stock Trading News Alert Project
## Overview:
This project monitors Tesla's stock prices. If an increase/decrease of 5% is observed between yesterday's and the day before yesterday's prices, then an email will be sent to the recipient.
-  Uses [Alpha Vantage API](<https://www.alphavantage.co/>) for fetching Tesla's Stock Prices
-  Uses [News Api](<https://newsapi.org/>) for fetcthing news related to Tesla
-  Uses [Ethereal Email](<https://ethereal.email/>) for send/receiving emails
