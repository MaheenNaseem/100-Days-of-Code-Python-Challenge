# Day 32 - Intermediate+ Send Email (smtplib) & Manage Dates (datetime)
This project explores automating email workflows using Python’s built-in smtplib module. Instead of relying on Gmail or Yahoo, I used Ethereal Email, a sandbox service designed for safe testing of email functionality.
## Practice Project: Quote Sending Automation
[Source Code](</Day 32/Quotes-Sending/main.py>)
1. Reads a collection of quotes from a CSV file.
2. Picks a random quote.
3. Sends the selected quote to the recipient’s email address.

## Main Project: Birthday Wisher
[Source Code](</Day 32/Birthday-Wisher-Project/main.py>)
1. Reads birthday data from a CSV file.
2. Compares today’s date with stored birthdays.
3. If a match is found, a random pre-written template is selected.
4. Sends a personalized birthday wish to the recipient’s email address.

## Key Concepts Practiced
1. Using smtplib for email automation.
2. Handling CSV files with pandas.
3. Automating workflows with datetime.
4. Safe email testing using Ethereal Email.
