# Day 35-Intermediate+ Keys, Authentication & Environment Variables: Send SMS
## Rain Alert - SMS service:
This program checks the weather conditions and sends the user an alert if it rains in the next 12 hours.
<br>
1. Uses the [Open Weather API](<https://openweathermap.org/>) for fetching weather conditions.
2. Uses [Twilio](<https://www.twilio.com/en-us>) to send alerts to the user (if it'll rain).
